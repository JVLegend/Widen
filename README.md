# Widen

Ministry content platform connecting **churches** to **young content creators**. Churches share sermons and teachings; creators turn them into viral short-form content to spread God's Word on social media.

## Features
- Churches upload sermons and create missions with guidelines
- Young creators make short-form content (Reels, TikTok, Shorts)
- Impact points system rewards creators for reach
- Real-time analytics dashboard
- Public creator ranking
- Full i18n support (English + Portuguese)

## Tech Stack
- Next.js 16 (App Router)
- Tailwind CSS v4 + shadcn/ui
- Prisma + PostgreSQL
- Recharts for analytics
- Framer Motion for animations

## Getting Started

```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```
